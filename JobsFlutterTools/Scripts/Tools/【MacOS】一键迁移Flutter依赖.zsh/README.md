# 一键提取 / 导入 Flutter 依赖

由 Flutter 工程右键菜单的“提取Flutter项目工程依赖 → 一键提取 Flutter 依赖”或“导入Flutter项目工程依赖 → 一键导入 Flutter 依赖”进入。此目录与上级完整 `Tools` 目录一并交付，使用同包 `FlutterDependencyMigration.dart`。

- 提取默认私库候选；直接回车只提取私库，输入任意字符（包括空格）再回车才全提取。Git / path 来源不一定在权限意义上私有；无法确认的原生来源会报告，不声称私库齐全。
- 输出父目录可输入或拖入，直接回车使用系统桌面。成功后直接回车打包 ZIP，非空输入保留目录且不压缩；ZIP 解压后逐文件比对完整目录；确认期间新增或改动文件会拒绝删除。核对通过后，直接回车保留原目录，非空输入才删除本次新产物。
- 导入接受完整迁移目录、按内容识别的 Pub / Gradle 缓存目录（名称可以改变），或同时包含它们的父目录。ZIP 先解压。空输入持续重新询问，Ctrl+C / EOF 取消。
- 导入扫描及确认后的“校验、备份并导入依赖”分别立即显示已耗时 `HH:mm:ss`；交互终端每秒刷新单行，纯文本终端及日志每十秒记录一次等待。每阶段完成、失败或中断后显示总用时并停止刷新，等待选择、备份确认和 `YES` 输入不计时。计时不表示完成百分比或剩余时间，小时数可超过 24。
- 预检展示来源、目标及缺失项，精确输入大写 `YES` 才合并。预检指纹绑定本次来源、目标与配置，确认期间发生变化则停止；普通文件内容冲突可按下述策略处理；不自动安装 SDK、下载依赖、执行工程脚本或拷贝账户凭据。
- 缓存同名文件内容不同（包括 Git 缓存 `.git/index`）时，先列出冲突，再用 [**fzf**](https://github.com/junegunn/fzf) 上下键选择“使用导入源的数据（推荐）”或“保留当前环境的数据”；`Esc` / `Ctrl+C` 取消。无可用 fzf 或非终端输入时回退编号，回车默认选导入源。
- 使用导入源：二次确认时直接回车备份，输入任意字符（包括空格）再回车则不保留备份、直接覆盖。备份位置可输入或拖入，空输入默认系统桌面；每次在所选位置新建一个文件夹，保存将被覆盖的旧文件和恢复清单，校验通过后再覆盖。备份失败不覆盖；不备份模式仍保留本轮失败撤回资料，成功后清理。
- 保留当前环境：跳过冲突文件，继续补齐其它缺失项，不询问备份。两种选择都先重新展示最终计划，再输入精确 `YES` 执行；来源或目标在确认后变化会停止。此选择仅处理已列出的普通文件内容冲突，不修改既有有效 vendor 保留策略。
- 最终 `YES` 确认处直接回车视为尚未输入，循环重新询问，不重新扫描依赖；输入其它非空内容取消，EOF / Ctrl+C 退出。备份确认与备份路径处的空回车默认值继续按上文执行。
- 备份确认的问句用默认文字颜色，“回车 = 备份”用绿色粗体，“任意字符再回车 = 不备份直接覆盖”用红色粗体。纯文本终端和日志不含颜色码。
- 已由工具导入且包声明有效的 vendor 覆盖按原路径保留，计划列出当前与快照版本，不升级现有包；只新增尚未覆盖的快照包和缺失缓存。全包保留时覆盖配置与 vendor 目录均不改。工具记录缺失、路径失效、自定义覆盖及链接／目录类型冲突仍拒绝；保留既有包不修复其内部损坏文件。
- Gradle 原始缓存与全量提取保留 `metadata-*/descriptors` 模块描述，排除共享可变 `.bin` 索引、`gc.properties` 和运行锁。制品已导入不等于解析记录完整或完全离线；工程将 SNAPSHOT 缓存时间设为 0 时，正常构建仍会请求原仓库校验元数据，仓库不可达须另行处理，不能只靠重复导入保证运行。
- 执行器优先复用项目 FVM Dart，其次使用已有可运行的原生 PATH Dart；后者只执行文件迁移内核，不切换工程 SDK。日志位于系统临时目录的 `JobsFlutterMigration.*` 文件。

从任意工作目录运行时，将以下相对路径替换为实际脚本位置，项目路径作为参数传入：

```shell
/bin/zsh ./【MacOS】一键迁移Flutter依赖.zsh --project "Flutter工程目录" --mode export
/bin/zsh ./【MacOS】一键迁移Flutter依赖.zsh --project "Flutter工程目录" --mode import
```

工具源码和隔离夹具验证不等于跨机离线构建或 Finder 真实安装验收。工具链、签名、私库权限及尚未缓存的制品仍需在目标电脑准备。
键盘选择使用 ↑/↓ 或 Tab 导航、回车确认；默认停在取消行，Esc / Ctrl+C 取消。子层按 ← 返回真实上一层，仍有效的查询会保留；候选变化后清空失效查询。返回、取消和选择器失败均不启动所选业务。

健康 fzf 直接复用；仅调用方已经确认的交互流程在缺失或损坏时沿 Homebrew 依赖链准备并复检。临时网络失败持续重试，Ctrl+C 可结束；确定的本地、认证、许可或版本错误停止。选择器不向 Shell 启动文件写入配置。只读检查不修复；非终端不等待交互。供 source 的库仅注册能力，不在加载时安装或重复确认。
