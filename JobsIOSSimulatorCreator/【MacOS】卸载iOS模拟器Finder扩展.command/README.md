## 🔥 <span id="前言">前言</span>

停用并注销固定 Bundle ID 的扩展，核验后删除其宿主 App，刷新 Finder；保留源码、所有模拟器与运行时。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、运行方式 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

双击 [【MacOS】卸载iOS模拟器Finder扩展.command](./【MacOS】卸载iOS模拟器Finder扩展.command)。先回车查看已注册路径，再输入精确 YES 执行卸载；其它输入取消。无交互输入停止；按 Ctrl+C 取消。

## <span id="jobs-toc-heading-3" data-jobs-toc="v2">二、环境与日志 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

仅支持 macOS；安装要求完整 Xcode、macOS SDK 与可用签名环境。源码与工程整体保留，路径由脚本自身解析。日志位于系统临时目录，文件名为 `同名脚本.log`。
