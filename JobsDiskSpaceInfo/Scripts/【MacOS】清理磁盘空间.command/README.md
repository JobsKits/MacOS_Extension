## 🔥 <span id="前言">前言</span>

[主脚本](./【MacOS】清理磁盘空间.command)是随右键 App 打包的独立原生 zsh 实现，参考[终端 clean](../../../../../JobsConfigOS/🌍JobsMacEnvVarConfigs/scripts/【MacOS】clean.command/README.md)，运行时不引用原脚本、外置函数库或 README。业务使用系统原生命令，Xcode 分组选择要求已有健康 fzf；缺失时明确停止阶段，不先扫描或自动安装。Homebrew 与 Xcode 缺失时相应可选能力跳过，不自动升级。

## 一、<span id="flow">顺序与确认</span>

点击 Finder 中的磁盘空间行会经当前扩展实际所属宿主，打开一个独立 Terminal。容量无法读取时同样可以进入；不把右键选中文件／目录作为清理目标。

1、先问是否进行 Xcode 清理：回车继续，任意文字再回车跳过；接受前不扫描。选择覆盖 Device Support、Simulators、SwiftUI Previews、DerivedData、Archives、Caches 六组。
2、每组 fzf 第一行默认为“本组全部清理”，下方可单选或多选具体项目；`↑↓`／`Tab` 移动，`Enter` 勾选，`Space` 确认当前组选择；没有勾选时确认高亮行，因此停在首行确认即全部。`Esc`／`←` 中止整个运行。全部组选择后展示准确范围，**回车确认清理，任意非空字符加回车取消本次 Xcode 清理并继续常规流程**；EOF／`Ctrl+C` 中止整个运行。不会覆盖跳过／未选项目。
3、Xcode 阶段完成、跳过或普通失败后，显示原六类清理的准确范围；按回车确认后进入常规清理。任意非空输入（包括空格）、EOF 和无交互环境均取消常规六类。`Ctrl+C` 取消。Xcode 普通失败会记入最终结果，常规成功也仍返回非零；前置阶段不会在常规重试时重跑。
4、确认后才建立本轮日志与互斥锁，再执行旧六类。各独立步骤失败仍处理其它步骤，随后列出未完成步骤并询问：**回车继续清理失败步骤，输入任意字符后回车结束**。每轮仅重试上一轮失败的常规步骤，已成功步骤与前置 Xcode 阶段不重跑；步骤内仍执行原有枚举、身份复检与安全检查，不新增权限或扩大清理类别。
5、用户缓存重试只处理首轮明确勾选、预检通过并最终确认后实际删除仍失败的候选；保护项出队，已成功项、清理后新生成项与被替换的同名项保留。根目录与原候选身份均重新核对；首次枚举失败时本轮不重新扫描，排障后需重新运行。开发 App 移动／注销重试仍按原规则重新核验候选，产生新变更后补刷新 Spotlight／Dock。
6、重试日志追加到同一文件，保留轮次、步骤名称与退出码；仍失败时再次询问。两阶段均成功或主动跳过 Xcode 且常规成功时返回零；任一阶段仍失败则返回非零。常规重试非空输入结束保留失败状态 `1`；EOF、无交互输入返回取消状态 `130`。步骤取消退出码保留，不当普通失败继续删除。结束不清屏，保留日志路径与结果；重新右键读取最新容量。

`--help` 只读展示用途。脚本不接受任意目标路径、自动确认或后台静默清理参数。运行时自述内置，不读取本文。

## 二、<span id="legacy">原六类功能映射</span>

| 原 clean 类别 | 本右键实现与保护 |
| --- | --- |
| zsh 历史／会话 | 仅当前用户标准 `.zsh_history` 与 `.zsh_sessions` 的 history/historynew 文件；拒绝链接与并发替换，不采用外部 HISTFILE。其它终端内存中的历史可能再次写回。 |
| Spotlight 开发 App | 仅当前用户、路径符合 Build/Products 或 build 下非 macOS Apple 产物的 App；逐层拒绝链接，校验身份后无覆盖移入私有废纸篓目录；正常 Applications 和模拟器 App 实体保留。 |
| LaunchServices 开发记录 | 先完整读取清单，仅注销当前用户的匹配开发 App；查询失败不以空结果继续回收，不进行全局 `-kill` 重建；按变化刷新用户级 Spotlight、corespotlightd、sharedfilelistd、Dock，界面可能闪烁。 |
| 实体缺失 iOS 模拟器 | 由先行 Simulators 组承接选择，跳过／未选在旧清理中保留。选中的孤儿仅限默认 CoreSimulator 设备集，UUID／状态／精确 dataPath 验证；目录或 device.plist 缺失才处理。残留数据先完整备份并核验，逐次复查后仅注销同一 UUID；仅 data 缺失、仅 Runtime 不可用与共享 Runtime 保留。 |
| Homebrew cleanup | 仅复用健康已有 Homebrew，运行 cleanup；不安装、升级或自动改变 tap 信任策略，错误进入本轮失败状态。 |
| 用户 Library/Caches | 完整枚举实际顶层候选，fzf 默认跳过；Space 确认已选集，无勾选时选定当前行；选中后通用预检并确认准确范围。开发依赖／源码标记、只读、链接、异盘或检查不完整的候选保留且不进入失败重试；逐项复核根与候选身份，保留根目录及未选内容。规则不依赖用户名或特定环境目录名。 |

Xcode 的六组位于 `Library/Developer` 等阶段明确展示的路径；其中 Caches 为 `CoreSimulator/Caches/dyld`。旧用户缓存只遍历 `Library/Caches`，不递归 Developer，因此不会在后续绕过 Xcode 跳过／未选结果。清理不保证释放固定容量；活跃应用可重新生成缓存。

用户缓存 fzf 使用 `↑↓`／`Tab` 导航、`Enter` 勾选／取消、`Space` 确认已勾选项；没有勾选时选定当前行并确认；首行为“全选用户缓存”，第二行为“跳过用户缓存清理”（默认焦点）。确认全选会展开本轮完整候选，搜索过滤不会缩小全选范围；同时勾选跳过时优先跳过，已有勾选不额外加入当前光标项。默认跳过行直接 Space 仍是跳过；搜索无匹配且无勾选时留在菜单。通过预检的准确范围再次确认：回车删除、非空输入跳过，EOF／取消停止。单候选检查预算为 10,000 项、64 层及操作间 5 秒检查，不承诺中断单次阻塞系统 I/O。识别到 `go.mod`、`package.json`、`pyvenv.cfg`、`package.xml` 等开发标记时整项保留；只逐成员复核并删除原授权快照内容，目录仅在空时移除，新成员不会被整树递归删除。保护是保守判断，仍须核对所选对象用途。

## 三、<span id="state">日志、恢复与生命周期</span>

删除、移动、备份和查询失败的具体系统错误（如 `Permission denied`）同时显示在终端并写入日志，不只给退出码和文件位置。机器输出保持独立，错误文字不混入 JSON／NUL 候选清单；Xcode 动作失败／取消时仅显示该动作新追加的日志，不回放历史错误，同一文件重定向不重复写入。业务失败及取消保留原退出码，日志写入失败也会返回非零状态。

只有已选、预检通过并确认的缓存候选及已确认的历史会直接删除，不经过废纸篓，无法自动恢复。位于 Caches 不等于垃圾：有开发依赖／源码结构或权限保护的候选整体保留，不用提权、改权限或整片强删去绕过。构建 App 进入当前用户废纸篓的 `JobsDiskSpaceCleanup-DevelopmentApps.*`；失效设备残留数据与原清单保存在 `JobsClean-SimulatorOrphans-*`，清空废纸篓前自行核对。脚本不清空废纸篓、不使用 sudo、不修改代理、系统安全设置或正常 App。

旧六类日志确认后才以 `umask 077` 在系统临时目录创建，名称为独立的 `JobsDiskSpaceCleanup.*`，仅当前用户可读写。同次运行的失败重试沿用该日志；不同运行不覆盖旧日志或同名链接，临时目录不可用或日志创建失败时明确报错并停止常规清理。模拟器 JSON 诊断目录同样打印在日志中。初始化会尝试取得当前用户的临时锁，已有锁时拒绝进入；当前函数级 `EXIT` trap 会在初始化返回时提前释放锁，完整流程的并发互斥尚待修正，不应同时启动多次清理。SIGKILL／断电可能遗留锁，脚本保留并报告准确路径，不自动接管。

宿主将完整脚本复制到权限受限的本轮临时目录，Terminal 运行该快照；原 App 更新／卸载不影响已经打开的本次脚本。正常退出回收载体，业务日志与恢复备份保留；强制结束整个进程树不承诺执行退出清理。

## 四、<span id="maintenance">对称维护与验证</span>

原终端 clean 与 macOS／Windows 右键 clean 为对称维护关系；今后原 clean 的增删改须在同一任务同步两端独立实现、参数／交互、脚本内置自述、README、隔离回归及打包运输。保持独立自包含，不通过运行时引用或共享外部代码完成同步。平台能力不同可采用等价功能或明确标注不适用，不能静默漏项。

本入口与原终端显示同一完整功能和风险自述；常规确认统一为回车继续，任意非空输入或输入结束取消，Homebrew tap 信任和日志位置保留入口差异。Xcode 与用户缓存选择、保护及失败重试按行为对齐。Windows 的 Xcode 类别不适用，其平台清理映射见[双端资产盘点](../../../../项目相关报告/磁盘空间信息资产盘点.md)。

[隔离测试](../../Tests/DiskCleanupTests.rb/README.md)只在临时 HOME 与命令替身中验证门禁、链接／并发保护、失败队列重试与取消传播；运输测试不打开真实 Terminal 或执行清理。隔离验证不代表真实 clean、缓存删除、注册安装或完整 Finder→Terminal 操作已验收。

询问提示的题干为青色粗体，仅回车选项为绿色粗体，任意字符／非空输入为红色粗体，分隔符普通且结尾复位；纯文本模式和日志不含 ANSI。普通日志、自述及 URL 不追加题干样式。中文渲染仅在 formatter 子进程使用 UTF-8 locale，不修改调用者语言环境。两份 Mac 源码的[真实 PTY 展示回归](../../../../../JobsConfigOS/🌍JobsMacEnvVarConfigs/scripts/clean.command/Tests/PromptStyleTests.rb/README.md)同时核对输入及 EOF 语义。
