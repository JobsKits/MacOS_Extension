## 🔥 <span id="前言">前言</span>

[SourceLayoutHelper.py](./SourceLayoutHelper.py) 只供本仓库测试读取源码使用，不参与安装或发布。`source_script()` 优先保留现有平铺文件，再定位同名包装；复制到临时 App 的资源名保持原样。`shell_library()` 只移除已确认位于文件末尾的入口调用，防止配置写入夹具误执行安装器。
