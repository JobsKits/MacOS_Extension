# 一键提取 / 导入 Flutter 依赖

由 Flutter 工程右键菜单的“提取Flutter项目工程依赖 → 一键提取 Flutter 依赖”或“导入Flutter项目工程依赖 → 一键导入 Flutter 依赖”进入。此目录与上级完整 `Tools` 目录一并交付，使用同包 `FlutterDependencyMigration.dart`。

- 提取默认私库候选；直接回车只提取私库，输入任意字符（包括空格）再回车才全提取。Git / path 来源不一定在权限意义上私有；无法确认的原生来源会报告，不声称私库齐全。
- 输出父目录可输入或拖入，直接回车使用系统桌面。成功后直接回车打包 ZIP，非空输入保留目录且不压缩；ZIP 解压后逐文件比对完整目录；确认期间新增或改动文件会拒绝删除。核对通过后，直接回车保留原目录，非空输入才删除本次新产物。
- 导入接受完整迁移目录、按内容识别的 Pub / Gradle 缓存目录（名称可以改变），或同时包含它们的父目录。ZIP 先解压。空输入持续重新询问，Ctrl+C / EOF 取消。
- 预检展示来源、目标及缺失项，精确输入大写 `YES` 才合并。预检指纹绑定本次来源、目标与配置，确认期间发生变化则停止；现有冲突不覆盖；不自动安装 SDK、下载依赖、执行工程脚本或拷贝账户凭据。
- 已由工具导入且包声明有效的 vendor 覆盖按原路径保留，计划列出当前与快照版本，不升级现有包；只新增尚未覆盖的快照包和缺失缓存。全包保留时覆盖配置与 vendor 目录均不改。工具记录缺失、路径失效、自定义覆盖或缓存内容冲突仍拒绝；保留既有包不修复其内部损坏文件。
- 执行器优先复用项目 FVM Dart，其次使用已有可运行的原生 PATH Dart；后者只执行文件迁移内核，不切换工程 SDK。日志位于系统临时目录的 `JobsFlutterMigration.*` 文件。

从任意工作目录运行时，将以下相对路径替换为实际脚本位置，项目路径作为参数传入：

```shell
/bin/zsh ./【MacOS】一键迁移Flutter依赖.zsh --project "Flutter工程目录" --mode export
/bin/zsh ./【MacOS】一键迁移Flutter依赖.zsh --project "Flutter工程目录" --mode import
```

工具源码和隔离夹具验证不等于跨机离线构建或 Finder 真实安装验收。工具链、签名、私库权限及尚未缓存的制品仍需在目标电脑准备。
