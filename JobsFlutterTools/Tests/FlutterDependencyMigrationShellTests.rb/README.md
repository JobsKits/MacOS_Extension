# Flutter 依赖迁移终端回归

在本目录运行 `ruby ./FlutterDependencyMigrationShellTests.rb`。使用系统 Ruby、zsh、ditto 和 unzip，在系统临时目录验证默认私库、非空全提取、改名缓存拖入、ZIP 默认保留及显式删除、已有 ZIP 冲突、引擎失败码、预检指纹与精确 YES 门禁，并用真实 Dart 和复制后的 Tools 资源验证导出 ZIP、改名缓存及迁移包导入；覆盖确认期间来源变化零写入、ZIP 后隐藏文件改动保留及原生分类归档 ZIP 的清单兼容。测试结束清理自己的临时夹具，不导入真实账户缓存、不安装或注册扩展。

冲突专项覆盖：导入源默认备份及拖入字面路径、系统桌面默认值、非空／空格选择不备份、保留本机跳过备份、逐层取消、最终计划指纹，以及已有 fzf 的真实 PTY 默认项、方向键和 Esc。真实文件备份、覆盖、保留、并发变化和失败撤回另由同级 Dart 内核回归验证；所有夹具均在临时目录。

`JOBS_TEST_TOOLS_DIR` 可指定已安装 App 的 `Contents/Resources/Tools`，复验实际打包脚本和内核；`JOBS_TEST_DART` 可指定已有原生 Dart，测试不会下载安装 SDK。

最终确认另覆盖连续空回车后精确 YES 仅执行一次、空回车后明确取消、EOF 不空转；真实菜单分发夹具验证空回车重问期间不丢失既有冲突策略。

等待反馈覆盖真实 PTY 内静默命令的每秒计时、阶段总用时、结束后停止刷新、超过 24 小时的格式、标准输入保留、纯文本十秒心跳与机器回执隔离，以及 TERM / HUP / INT 中断后返回原状态并回收本轮子进程；不访问真实依赖缓存。
