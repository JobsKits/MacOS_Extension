## 🔥 <span id="前言">前言</span>

[SourceLayoutHelper.rb](./SourceLayoutHelper.rb) 是测试专用 Ruby 模块：将源码旧路径解析到同名包装，分别取得逻辑资源目录，并在旧平铺发布夹具中保留原文件名。Shell 子夹具内联同一原生解析函数；生产脚本不引用此模块。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、使用与验证 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

测试通过相对 `require_relative` 加载，依赖系统 Ruby 标准库；导入不打印、不确认、不执行真实业务。路径映射对应当前维护源码，旧平铺断言保持原协议。整体复制工程后运行上级测试；源码地址、夹具目标与机器输出不能混用。
