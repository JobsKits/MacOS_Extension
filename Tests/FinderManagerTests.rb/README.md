## 🔥 <span id="前言">前言</span>

使用系统 Ruby / Minitest 和 `/bin/zsh` 隔离验证总管理器的选择、分发、取消、失败与安装后验顺序。全部业务命令使用替身与临时文件，不安装、卸载或登记真实扩展。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、运行方式 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

```shell
ruby "./FinderManagerTests.rb"
```

测试依据自身目录定位源码，支持目录整体搬迁；中文与空格路径和旧发布平铺协议分别由配套套件覆盖。失败保留真实退出状态，详细输出见当前终端。

共享模块的替身匹配实际 `jobs_layout_file` 调用，核对只转交所选叶 ID、真实 worker 失败码继续上报，以及共享单元失败按菜单项展开；不会因源码路径包装变化而误调用临时目录中的缺失脚本。

重复卸载矩阵覆盖项目工具、桌面工具、Flutter、终端及 iOS 五类共享模块的全无需卸载和混合请求；合法配置中的已关闭叶归入独立 `not-installed` 终态，真正处理叶保留成功／失败，原始退出码 `3`／`37`／`77` 不会被误当作无需卸载。配置损坏、链接、另一安装位置和缺配置兼容分别验证。
