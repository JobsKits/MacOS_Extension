# SDK 自动获取隔离回归

执行 `ruby ./SdkAcquisitionRetryTests.rb`。使用临时假 SDK 验证超过固定次数的持续重试、124 超时继续、确定本地错误、用户退出、向父进程发送 TERM 后清理忽略 TERM 的子进程，以及两个 Flutter 运行入口的首次补齐窗口。日志与机器输出分别核对，不下载 SDK、不安装环境、不启动真实项目。

同时覆盖 exit 0 但明确下载失败、FVM 返回成功但缺实际入口、Gradle 私有损坏分发保留并重取、无效formula / SDK组件不无限重试，以及目标平台预缓存与设备映射。

**终端配色保护：** `SdkAcquisitionRetryTests.rb` 直接运行时，在可可靠保存与恢复配色的交互终端中临时使用黑底白字和统一强调色；正常退出、失败及可捕获中断后恢复进入前的配色，保留原业务清理和退出状态。导入本文件不接管终端；无法可靠保护、纯文本模式或无交互终端时按纯文本约定降级。运行中另行修改的颜色会保留并报告冲突，强制终止后可按运行提示使用独立恢复入口。 此实现保留原解释器选项和预载状态；无可用 fork、Windows 或预载多线程时不重启脚本，以纯文本继续。
